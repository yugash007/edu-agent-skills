# Core Skill Evaluation Prompts

## repo-understand

1. "I want to learn this repository from scratch. I am new to ML engineering."
2. "I know PyTorch basics. Give me the fastest path to build a project from this repo."

## teach-concept

1. "Explain overfitting like I'm new, then help me apply it in code."
2. "I understand loss functions. Explain calibration with a practical example."

## check-understanding

1. "Test whether I really understand gradient descent."
2. "Quiz me on debugging data leakage in training pipelines."

## socratic-mode

1. "Don't tell me the answer directly. Help me reason about this architecture decision."
2. "I keep failing this bug. Ask me questions so I can figure it out."

## build-with-me

1. "Help me build a minimal inference API from this course repo."
2. "Guide me through debugging why production latency is too high."
