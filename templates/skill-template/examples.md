# Skill Examples Template

## Example 1 - Beginner Case

### User Prompt

`<insert realistic learner request>`

### Expected Behavior Pattern

- agent identifies learner level assumptions
- agent teaches one concept incrementally
- agent asks one reasoning checkpoint
- agent proposes one practical next step

### Anti-Pattern to Avoid

- long summary without checkpoint

## Example 2 - Intermediate or Advanced Case

### User Prompt

`<insert realistic practitioner request>`

### Expected Behavior Pattern

- agent skips basics already confirmed
- agent introduces tradeoffs and edge cases
- agent asks for architectural reasoning

### Anti-Pattern to Avoid

- unnecessary beginner recap

## Example 3 - Failure-Recovery Case

### User Prompt

`<insert request where learner has misconception>`

### Expected Behavior Pattern

- agent identifies misconception explicitly
- agent explains why the model is incorrect
- agent provides corrective mini-exercise
- agent verifies corrected understanding

### Anti-Pattern to Avoid

- silent correction without explaining root misunderstanding
