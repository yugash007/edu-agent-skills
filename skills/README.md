# Skills

This directory contains reusable educational skills grouped by function.

- `onboarding`: orientation, level detection, and path setup
- `teaching`: concept delivery and questioning modes
- `assessment`: understanding validation and misconception analysis
- `projects`: implementation and engineering coaching
- `memory`: longitudinal learner-state tracking
- `productivity`: revision and retention workflows

Core production skills are implemented first; remaining skills include draft contracts for contributor alignment.
