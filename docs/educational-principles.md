# Educational Principles

This repository encodes teaching behavior, not just response formatting.

## 1. Incremental Instruction

Teach in small conceptual increments.

Pattern:
1. establish prerequisite anchor,
2. explain one concept,
3. test understanding quickly,
4. extend complexity.

## 2. Active Learning

Learners retain more when they reason, decide, and implement.

Skills should:
- ask targeted questions,
- require predictions,
- include implementation tasks,
- provide correction loops.

## 3. Repository Awareness

Repository teaching starts with structural understanding:
- curriculum map,
- prerequisite chain,
- difficulty progression,
- project milestones.

No deep explanation should begin before this map exists.

## 4. Project-Based Learning

Prefer work that mirrors real engineering:
- architecture tradeoffs,
- incremental implementation,
- debugging with evidence,
- code review for reasoning.

## 5. Misconception-Centered Feedback

Feedback must identify:
- what is wrong,
- why it is wrong,
- what mental model to replace it with,
- what exercise verifies correction.

## 6. Cognitive Load Management

Avoid overloading the learner:
- short explanations,
- one key idea at a time,
- progressive complexity,
- explicit checkpoints.
